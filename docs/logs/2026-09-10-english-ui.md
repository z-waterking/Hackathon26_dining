# 2026-09-10 · 英文版本与右上角切换

## 实现

- 添加共享 I18n provider、中文默认词表、右上角语言切换与 localStorage 偏好；更新 document lang/title。组件不按语言重建，保留hash页面、表单草稿和进行中的请求。
- 反馈、Action、六周菜单、菜品资料、消费分析、Prompt配置及通用弹窗/分页/状态/表单支持英文，补移动端与英文长文排版。
- 按补充要求，原始反馈正文及证据引用、实际菜单菜名/档口/固定主食保留中文。状态/类别/表单选项显示英文但提交原始值，原始CSV/XLSX导出未改。源文件名、ID、路径作为可追溯标识保留，原始审计记录不修改。
- 动态 Action/规则/Prompt/审核说明和摘要通过已配置 Azure Responses 模型生成英文显示译文，严格校验结果完整性；版本+原文字段哈希作为缓存键存到独立meta记录。静态界面不调用AI，中文界面不排队翻译，切回中文暂停未发出的翻译。
- 只对当前可见页面请求翻译，长预览与运行留痕展开后处理；合并小批次、服务端串行去重，失败用英文提示、手动重试。后台排菜与业务审批不因翻译等待锁住。
- 每个页面会话自动排队最多200段/40,000字符（重试计入额度），每批20段/10,000字符；达到额度后英文提示暂停，明确点击Continue translation继续下一批，切换语言不自动重置额度。这是前端请求保护，不是服务端账户预算。
- LocalizedInput/Textarea显示译文但不触发onChange；只有用户键入才改草稿，未修改字段仍提交原文。切语言本身不写入反馈、Action、Prompt或规则配置，不改变菜单快照和缓存有效性。
- 修复译文编辑框在409配置冲突后“重新加载”仍残留旧输入的问题；显式加载服务端值可正确清除本地编辑。手机英文导航使用独立宽度横向滚动，避免长标题挤压重叠。
- 补齐开放反馈渠道/类别、菜品标签核验说明、AI回复草稿等英文显示；Catalog表单使用保留原值的序列化，避免未编辑译文自动写回中文字段。
- 运行留痕与Action历史快照按字段白名单生成仅显示的英文投影：规则/事项/检验说明翻译，原反馈引用、菜单、ID/文件字段保持不变；展开才请求译文，不新增后端字段或暴露原本隐藏的Prompt。
- 依据 OpenAI Docs 核对 Responses 结构化输出约束，保持原模型/endpoint，用独立 ui_translation 角色记录用量；不向浏览器提供密钥。
