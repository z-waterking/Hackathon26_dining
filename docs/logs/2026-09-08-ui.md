## Windows 浏览器测试收尾修复

- 复现并用 Playwright 的 `pw:webserver` 日志确认：测试断言通过后停留在 `Terminating the WebServer`。本地安装的 Playwright 1.63 在 Windows 明确不支持 webServer graceful shutdown，退回 shell 子进程树终止逻辑。
- 把隔离 Fastify 服务改由 Playwright `globalSetup` 在 runner 内创建，并返回确定性的 teardown；不再使用 Windows shell 子进程及 signal 关闭。
- teardown 只关闭本次测试服务的连接、SQLite 连接和随机临时目录；删除前验证目录在系统临时根下且符合专用前缀，不停止其他 Node 服务。
- 服务启动失败也会回收当前测试资源，避免端口被占用等失败场景留下数据库。
- 最终验证：`npm --prefix app run test:e2e` 桌面/移动端共 10 项通过（40.9 秒），正常自行退出，exit code 0。静态检查和 diff 空白检查通过。
- 新增反馈回复/Action、词云、运营设置、菜单工作流四类页面截图供视觉核验。一次并行构建导致 `dist` 暂时被清空、旧用例访问返回 404；停止并行构建后全量重跑通过。

## 上传旧表并在系统展示新表

- 根据用户纠正，主入口替换为“上传旧表 Excel”，接受任意文件名的 `.xlsx` 原始 Forms 工作簿；文件通过二进制上传接口发送，前端检查非空及 10 MB 限制。
- 系统自动转换入库；上传完成清空旧的月份/搜索/类型/状态筛选，自动展示“转换后的新表”。不再要求固定文件名或由用户上传目标模板。
- 新增十列目标表格，支持横向滚动、每页 12 行、完整长正文和从每行进入原有回复/跟进/Action 流程。
- 历史批次可“查看新表”，刷新默认展示最近上传批次；继续保留目标 XLSX/CSV 下载及转换报告。
- 新增真实 API 浏览器用例：ExcelJS 动态构造 13 条合成旧格式记录，经文件上传验证十列映射、分页、人工回复保留、重导幂等与重载展示。上传文件与转换产物都落在隔离测试根目录并随测试清理。
