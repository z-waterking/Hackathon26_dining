# 2026-09-10 · 提交型弹窗生命周期

## 请求

Action 保存调整、批准、拒绝成功后关闭弹窗，同时检查类似交互。

## 修改

- Action 三种操作在 API 成功分支关闭编辑窗；失败或表单校验不通过时保留输入，接口错误在弹窗内显示。不把通用 `run()` 返回当作写入成功。
- 共享 Modal 支持提交态：禁用输入、按钮、关闭按钮与 Escape；Action、反馈录入/跟进/导入、菜品资料、换菜和历史结果读取采用一致保护，避免旧请求结束时关闭后来重新打开的草稿。
- `Workbench.run()` 增加同步引用互斥，补上 React 状态更新前的重复提交窗口。
- 刷新失败单独显示提示并保留已经加载的页面/草稿；写入成功仍然完成关闭，不要求用户重复保存。
- AI 起草、保存回复、月报生成、菜单修复/检验属于窗内辅助操作，保留窗口供继续编辑或查看结果；反馈回复期间冻结输入，避免新键入内容被迟到结果覆盖。
- 审查确认反馈录入、保存跟进、导入、资料保存、换菜、历史草案及生成结果读取已在成功分支关闭，保留既有业务行为。
- 锁定仅用于当前提交：后台 AI 生成期间，已有 Action 和草案列表仍可打开查看、关闭；不会因为后台任务把浏览窗口锁住。
